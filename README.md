<h1>Black Hole Simulation</h1>
<p>A 3D black hole simulation built with Python, Pyglet, and NumPy.</p>
<p>With the help of AI for shaders, states, camera, etc given by my teacher assistant from one of my courses</p>

The project simulates meteors being attracted by a black hole's gravitational field. Meteors can collide with each other, generating debris fragments that continue to move under the influence of gravity.

Features
3D camera controls
Black hole gravitational attraction
Random meteor spawning
Meteor-to-meteor collision detection
Collision response using impulse physics
Debris generation after impacts
Dynamic lighting
Real-time simulation using Pyglet
Controls
Key	Action
A	Rotate camera left
D	Rotate camera right
Q	Clear all active meteors
