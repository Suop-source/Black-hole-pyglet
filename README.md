# Black Hole Simulation

A 3D and 2D black hole simulation built with Python, Pyglet, and NumPy. 

*With the help of AI for shaders, states, camera, etc., provided by the teaching assistant from one of my courses.*

---

The project simulates meteors being attracted by a black hole's gravitational field. Meteors can collide with each other, generating debris fragments that continue to move under the influence of gravity.

### Features
* **Gravity & Physics:** Real-time black hole gravitational attraction.
* **Meteors:** Random meteor spawning and active movement.
* **Collisions:** Meteor-to-meteor collision detection using impulse physics.
* **Debris:** Dynamic generation of debris fragments after impacts.
* **Visuals:** Dynamic lighting and 3D camera controls.
* **Performance:** Real-time simulation rendering using Pyglet.

---

### Controls

| Key | Action |
| :--- | :--- |
| **A** | Rotate camera left |
| **D** | Rotate camera right |
| **Q** | Clear all active meteors |
